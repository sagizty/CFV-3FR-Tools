# Third-party resources / 第三方资源说明

The maintainer supplied these two collections as open-source third-party style recreations. The app and GitHub release use the same 36 looks. Application source code is MIT-licensed; this notice records the supplied resources' provenance and preserves their source metadata. The supplied folders did not include an upstream project URL or license text; no specific upstream license is assigned here.

维护者将以下两套素材作为第三方开源风格复现提供。App 和 GitHub 使用同一套 36 个预设。应用代码使用 MIT；本文件记录素材来源和关联文件中的原有署名信息，不改变原素材的授权。

## Fuji style recreations — 34 looks / 富士风格复现 34 款

- Files: `Resources/LUTs/Fuji-Recreation/`
- Copyright metadata in associated XMP: `浮光未央`
- Contact metadata: `咸鱼：浮光未央素材研究所`
- Exporting tool in CUBE headers: John R. Ellis Export LUT 1.24.0
- Declared profile: Rec709gamma2.4.icc

The two supplied software-specific CUBE sets contain the same 34 byte-identical tables under different filenames. Only one set is included. Original generator comments remain. The exporting computer's absolute path was removed from the color-profile comment; all numerical LUT data is unchanged. The [Export LUT website](https://johnrellis.com/lightroom/exportlut.htm) documents the exporting tool, rather than the origin of these particular looks.

## Provenance / 文件对照

Original filenames, original and bundled SHA-256 hashes, metadata cleanup and encoding choices are recorded in `Resources/LUTs/PROVENANCE.json`. The 36 looks are style recreations, with no exact match to official in-camera rendering claimed. Product names describe the looks; this independent application has no affiliation with the camera manufacturers.

原文件名、原件和打包文件的 SHA-256、注释清理及色彩空间配置见 `Resources/LUTs/PROVENANCE.json`。富士只选一套相同的 CUBE；Kodak 仅保留 1930s 和 64 调整。它们是第三方风格复现，不代表相机厂商官方色彩配置。
